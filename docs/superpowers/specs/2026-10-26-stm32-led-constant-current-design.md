# 可调恒流 LED 照明驱动系统设计文档

- 日期：2026-10-26
- 主控：STM32F103C8T6 最小系统板
- 题目：重庆移通学院第十届电子设计竞赛 C 题（大一、大二年级组）
- 目标范围：基本要求 + 发挥项 1（PWM 调光、多档定时）
- 开发环境：Keil MDK 5 + ST-Link（SWD）
- 状态：设计已确认，进入实施计划阶段

## 1. 项目概述

设计一个 5V 输入、20mA~200mA 连续可调、按键控制、数码管显示实际电流的恒流 LED 驱动系统。系统由模拟恒流环和 STM32 控制部分组成：模拟部分负责稳定 LED 电流，单片机负责设定值、测量显示、PWM 调光、定时和保护逻辑。整机焊接在洞洞板上，装入亚克力外壳，不使用成品 LED 驱动模块。

## 2. 需求分解

| 题目要求 | 实现方式 | 优先级 |
|---|---|---|
| 输入 5V，输出 20~200mA 连续可调 | 5V/2A 适配器供电；低边线性恒流；1mA 步进 | 必须 |
| 按键或电位器调节，数码管显示输出电流 | 4 个按键；4 位共阴数码管动态扫描；显示实测电流 | 必须 |
| 输出开路/过压保护 | 软件开路检测 + 输出端 5.6V 稳压管 + 故障锁存 | 必须 |
| 输出短路不损坏电路 | 恒流限流 + 500mA 保险丝 + IRLZ44N 热裕量 + 软件短路检测 | 必须 |
| LED 无明显闪烁 | 基本模式为直流恒流；PWM 调光频率 500Hz | 必须 |
| PWM 调光 | PA7 500Hz 斩波参考电压，亮度 10%~100% | 发挥 1 |
| 多档位定时开关灯 | 30s/1min/5min/10min，支持定时关灯和定时开灯 | 发挥 1 |
| 恒流精度 ≤3% | 三点校准（20/100/200mA）；作为可选冲刺目标 | 发挥 3（可选） |
| 数码管动态扫描 | 单片机直接扫描 4 位共阴数码管，不使用 TM1637 模块 | 必须 |
| 亚克力/塑料外壳 | 成品亚克力项目盒或自制亚克力板，手工开孔 | 必须 |
| 不能购买成品 | 驱动电路、显示、外壳均自行焊接和装配 | 必须 |

## 3. 方案选择

| 方案 | 原理 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A 线性恒流 | 运放 + N-MOS + 采样电阻闭环 | 无电感、纹波小、无闪烁、调试直观 | 效率约 65%，功率管发热 | 采用 |
| B 开关恒流 | Buck 恒流 IC + 电感 | 效率高、发热小 | 5V 输入压差小，低端 20mA 难控，布局要求高 | 一周内风险大，不采用 |
| C 线性恒流 + DAC | MCP4725 或数字电位器给参考 | 参考精确、软件简单 | 多一个模块和 I2C 调试 | 可作为后期精度备选 |

选择方案 A。核心原因：5V 输入、单颗 1W LED、200mA 以内的功率等级，线性方案的总功耗和发热完全可控，且没有电感纹波和开关噪声，最容易满足“无明显闪烁”和一周内完成的要求。

## 4. 系统架构

```
        5V/2A ──保险丝──1N5819──┬── 4.7V ── LED ── IRLZ44N ── 1Ω ── GND
                                 │                    (D)       (S)
                                 │                     │         │
                                 │                     │         └── LM358 A 反相输入
                                 │                     │              LM358 A 输出─100Ω─栅极
                                 │                     │              LM358 A 同相输入←Vref
                                 │                     │
                                 │              100k/100k 分压 → PA2
                                 │
                                 └── STM32 最小系统板 5V 引脚（USB 不插）

STM32F103C8T6
  PA8  TIM1_CH1 20kHz PWM → 10k/10µF → 1k/100nF → Vref
  PA7  TIM3_CH2 500Hz PWM → BSS138 斩波 Vref（PWM 调光）
  PA1  ADC ← LM358 B ×10 电流采样放大
  PA2  ADC ← 输出节点电压（开路/短路判断）
  PB12~PB15  按键 MODE/UP/DOWN/START
  PA3~PA6    数码管位选（S8050）
  PB0/PB1/PB5~PB10  数码管段选（330Ω）
```

信号链：

1. 目标电流 → PWM 占空比 → RC 滤波 → Vref（20~200mV）。
2. Vref 与 1Ω 采样电阻电压比较 → LM358 控制 IRLZ44N 栅极 → 稳定 LED 电流。
3. 采样电压 ×10 → ADC → 数码管显示实际电流。
4. 输出节点电压 → ADC → 开路/短路判断。
5. PA7 斩波 Vref → LED 电流在“设定值/0”之间切换 → PWM 调光。
6. SysTick 定时 → 按键扫描、数码管扫描、定时倒计时。

## 5. 硬件设计

### 5.1 功率回路

- 输入：5V/2A 适配器，经 500mA 保险丝和 1N5819 防反接，得到约 4.7V 功率轨。
- 负载：1W 白光 LED，Vf 3.0~3.4V，额定 350mA，实际最大 200mA，必须带散热片。
- 功率管：IRLZ44N，TO-220 封装，逻辑电平，Vgs=3.3V 时可导通；加小散热片。
- 采样电阻：1Ω，1%，1W 金属膜电阻；200mA 时压降 0.2V，功耗 0.04W。
- 功率路径：4.7V → LED 阳极 → LED 阴极 → IRLZ44N 漏极 D → 源极 S → 1Ω → 星形地。
- 200mA 正常工作时功率管功耗约 (4.7 - 3.2 - 0.2) × 0.2 = 0.26W；短路时约 (4.7 - 0.2) × 0.2 = 0.9W，TO-220 加小散热片可承受。

### 5.2 恒流环

- 运放：LM358 双运放，A 路做恒流环，B 路做电流测量放大。
- LM358 A 引脚：3 脚同相输入接 Vref，2 脚反相输入接 1Ω 上端（MOS 源极），1 脚输出经 100Ω 接 IRLZ44N 栅极。
- 栅极 10k 下拉到地，保证复位或运放失电时功率管关断。
- 反馈补偿：1nF 电容跨接在 1 脚和 2 脚之间；若振荡，加大到 10nF 或串 10k 电阻。
- 运放电源：8 脚接 4.7V，4 脚接星形地，电源脚旁放 100nF。
- 工作过程：电流增大 → 1Ω 上端电压升高 → 反相输入升高 → 运放输出降低 → MOS 栅极电压降低 → 电流回落，形成负反馈。
- 开尔文接法：1Ω 上端单独走一根线到 LM358 2 脚；1Ω 下端单独走一根线到运放地，避免大电流地线压降引入误差。

### 5.3 参考电压与 PWM 调光

- PA8 输出 TIM1_CH1，20kHz，PSC=0，ARR=3599。
- 两级 RC：PA8 → 10k → 10µF 到地 → 1k → Vref 节点 → 100nF 到地 → LM358 3 脚。
- 占空比 0.606%~6.06% 对应 Vref 20~200mV，对应 20~200mA。
- PWM 调光：BSS138 漏极接 Vref，源极接地，栅极经 1k 接 PA7，栅极 10k 下拉。
- PA7 输出 TIM3_CH2，500Hz，PSC=71，ARR=1999。
- PA7 高电平 → BSS138 导通 → Vref 被拉到约 0 → LED 电流关断；PA7 低电平 → LED 按设定电流点亮。
- 亮度占空比 = 1 - PA7 占空比；软件里设置 CCR2 = ARR2 × (100 - 亮度百分比) / 100，亮度 100% 时 CCR2=0。
- 500Hz 高于人眼闪烁融合频率，且每次导通时间足够运放建立，兼顾无闪烁和调光线性。
- Vref 节点对地加 100k 泄放电阻，MCU 复位或 PWM 停止时给滤波电容提供放电回路；约 1% 参考误差通过校准消除。
- 若 10% 低亮度偏差明显，可把 Vref 对地的 100nF 改为 47nF，提高参考恢复速度。

### 5.4 电流测量

- LM358 B 接成同相放大：5 脚经 10k 接 1Ω 上端，5 脚对地 1µF 滤波；6 脚经 1k 到地、经 9.1k 接 7 脚；7 脚经 100Ω 到 PA1，PA1 对地 100nF。
- 增益 = 1 + 9.1k/1k = 10.1。
- 20mA 时输出约 0.202V，200mA 时约 2.02V，落在 3.3V ADC 量程内。
- 输入 10k/1µF 低通截止约 16Hz，用于滤掉 PWM 调光时的电流斩波，得到平均电流；响应约 10ms，不影响显示。
- 10k 电阻与 LM358 输入偏置电流会产生约 0.45mV 失调，通过校准消除。

### 5.5 数码管与按键

- 显示：4 位共阴数码管，0.56 英寸，动态扫描；优先选红色或绿色，3.3V 直接驱动亮度足够，蓝色/白色段压高会偏暗。
- 段选：a=PB0，b=PB1，c=PB5，d=PB6，e=PB7，f=PB8，g=PB9，dp=PB10，每段串 330Ω。
- 位选：D1=PA3，D2=PA4，D3=PA5，D4=PA6，各经 1k 基极电阻驱动 S8050 NPN，集电极接对应共阴端，发射极接地，基极 10k 下拉。
- 扫描：SysTick 每 1ms 切换一位，每位刷新率 250Hz；换位前先关闭所有位选，写入段码后再开对应位，消除重影。
- 按键：PB12=MODE，PB13=UP，PB14=DOWN，PB15=START，按键另一端接地，使用内部上拉；每个按键并联 100nF 硬件消抖，软件 20ms 消抖。
- 长按：MODE 长按 1s 为紧急关断；START 在定时页长按 1s 启动定时开灯。

### 5.6 保护设计

- 输入保险丝：500mA，正常 200mA 不熔断，功率管击穿或输入反接时切断。
- 防反接：1N5819 串联在输入端，反接时截止。
- 输出过压：输出节点对地接 5.6V/0.5W 稳压管，正常 1.5V、短路 4.7V 都不导通，抑制高于 5.6V 的瞬态。
- 开路检测：输出开启且目标电流非零，直流模式下平均电流持续低于 1mA 达 500ms，PWM 调光模式下持续 1s，判定开路，关断输出并显示 `OPEN`。
- 短路检测：直流模式（亮度 100%）下，输出节点电压高于 4.2V 且电流大于 10mA 达 200ms，判定短路，关断输出并显示 `SHOr`。
- 过流检测：直流模式下实测电流连续两次大于 220mA，立即关断，显示 `OC`；PWM 调光时由硬件限流、保险丝和 IRLZ44N 热裕量保护。
- 故障锁存：故障后输出保持关闭；排除故障后按 START 清除，再按 START 恢复输出。
- PWM 调光时关闭短路检测，因为斩波期间输出节点电压平均值会被拉高；此时依靠 500mA 保险丝、恒流环限流和 IRLZ44N 热裕量保证不损坏。
- 栅极 10k 下拉、运放电源 100nF、功率轨 100µF+100nF，抑制上电和负载突变干扰。

### 5.7 供电与接地

- 5V/2A 适配器同时给 STM32 最小系统板 5V 引脚和 LED 驱动供电；板载 USB 口不插，避免双电源冲突。
- 星形接地：适配器负极、1Ω 下端、LM358 4 脚、MCU 地、数码管地全部在一点汇合。
- 功率地（LED→MOS→1Ω）用粗线短距离走；信号地单独走，避免 200mA 电流在地线上产生压降。
- 4.7V 功率轨靠近功率管放 100µF/16V 电解 + 100nF 陶瓷；LM358 电源脚放 100nF；数码管电源放 100nF。
- ST-Link 只接 SWDIO、SWCLK、GND 三根线；板子由 5V 适配器供电，不接 ST-Link 的 3.3V，避免与板载 LDO 冲突。

## 6. 软件设计

### 6.1 模块划分

| 模块 | 职责 |
|---|---|
| `main.c` | 初始化、主循环、任务调度 |
| `bsp_pwm.c` | TIM1 参考 PWM、TIM3 调光 PWM、输出使能 |
| `bsp_adc.c` | PA1/PA2 ADC 采样、平均值滤波 |
| `bsp_display.c` | 4 位数码管扫描、段码表、消隐 |
| `bsp_keys.c` | 4 按键扫描、消抖、短按/长按/连发事件 |
| `app_control.c` | 目标电流、占空比换算、校准、保护状态机 |
| `app_ui.c` | 页面切换、显示内容、定时倒计时 |
| `calib.h` | 三点校准常数 |

### 6.2 系统状态机

| 状态 | 输出 | 显示 | 进入条件 | 退出条件 |
|---|---|---|---|---|
| `SYS_OFF` | 关 | `OFF` | 上电默认；START 关闭 | START → `SYS_ON` |
| `SYS_ON` | 开 | 实测电流 | START 开启；定时结束 | START/长按 MODE → `SYS_OFF` |
| `SYS_TIMER_OFF` | 开 | `o000~o600` 倒计时 | 定时页启动定时关灯 | 倒计时到 0 → `SYS_OFF`；MODE → `SYS_ON` |
| `SYS_TIMER_ON` | 关 | `n000~n600` 倒计时 | 定时页启动定时开灯 | 倒计时到 0 → `SYS_ON`；MODE → `SYS_OFF` |
| `SYS_FAULT_OPEN` | 关 | `OPEN` | 开路判定 | 故障消失 + START → `SYS_OFF` |
| `SYS_FAULT_SHORT` | 关 | `SHOr` | 短路判定 | 故障消失 + START → `SYS_OFF` |
| `SYS_FAULT_OC` | 关 | `OC` | 过流判定 | 故障消失 + START → `SYS_OFF` |

页面状态 `g_page` 与输出状态独立：0=电流页，1=PWM 页，2=定时页。切换页面不改变输出状态。

### 6.3 按键与显示

- `MODE` 短按：电流页 → PWM 页 → 定时页 → 电流页；定时运行中短按取消定时并回到电流页。
- `MODE` 长按 1s：紧急关断，取消定时，回到电流页，显示 `OFF`。
- `START` 短按：电流页/PWM 页切换输出开关；定时页启动定时关灯。
- `START` 长按 1s：定时页启动定时开灯。
- `UP/DOWN`：电流页 ±1mA，按住 500ms 后每 100ms 连发一次；PWM 页 ±5%；定时页切换档位。
- 电流页：输出开时显示实测电流，如 `0200`；输出关时显示 `OFF`。
- PWM 页：显示 `d050`，范围 `d010`~`d100`；100% 为直流恒流。
- 定时页：显示 `t030`，档位 0/30s/60s/300s/600s；启动后显示 `o030` 或 `n030` 倒计时。
- 故障页：显示 `OPEN`/`SHOr`/`OC`，故障未排除时按 START 无效。
- 显示刷新 100ms 更新一次缓冲区；扫描在 SysTick 中断里完成。

### 6.4 校准方案

- 控制校准：在 20mA、100mA、200mA 三个点，用万用表实测电流，调整 CCR1 使实际电流等于目标值，记录三个 CCR1 值。
- 显示校准：在同一三个点记录 PA1 的平均 ADC 码值，建立 ADC→mA 的映射。
- 两点之间线性插值，区间外钳位到端点。
- 校准常数写入 `calib.h`，编译进固件；时间允许时增加“长按 UP+DOWN 进入校准模式，写入 Flash”的功能。
- 若 20mA 点无论怎么调都偏大，说明 LM358 失调过大，换 TLC2272 后重新校准。
- 三点校准后目标误差 ≤3%；若达不到，优先保证基本功能和显示准确，不为冲刺指标牺牲稳定性。

### 6.5 保护逻辑

- 每 10ms 采样一次电流和输出节点电压，连续 16 次平均。
- 过流：直流模式下电流 >220mA 连续 2 次（20ms）→ `SYS_FAULT_OC`；PWM 调光时由硬件限流和保险丝保护。
- 开路：输出开启、目标 ≥10mA，电流 <1mA；直流模式持续 500ms，PWM 模式持续 1s → `SYS_FAULT_OPEN`。
- 短路：亮度 100%、输出节点 >4.2V、电流 >10mA 持续 200ms → `SYS_FAULT_SHORT`。
- PWM 调光时不做短路检测，避免斩波期间输出节点平均电压误判。
- 故障时立即 `CCR1=0`、`CCR2=0`，关闭输出；故障标志锁存。
- 清除故障：条件消失后按 START，状态转到 `SYS_OFF`，再按 START 恢复输出。

### 6.6 定时功能

- 档位：30s、1min、5min、10min，另有 0 表示关闭定时。
- 定时关灯：启动时确保输出开启，倒计时期间正常恒流/调光，到 0 关断。
- 定时开灯：启动时关闭输出，倒计时期间显示剩余时间，到 0 按当前目标电流和亮度开启。
- 倒计时基于 SysTick 1ms 计数，显示秒数（最大 600，显示 `o600`/`n600`）。
- MODE 取消定时：定时关灯取消后保持输出开启；定时开灯取消后保持输出关闭。
- 定时结束后自动回到电流页。

## 10. 合规性说明

- STM32 最小系统板和 ST-Link 属于开发平台，不是成品驱动模块。
- 恒流功率电路、显示驱动、按键、保护电路全部自行焊接在洞洞板上。
- 数码管为裸 4 位共阴数码管，由 STM32 直接动态扫描，不使用 TM1637 等成品显示模块。
- 外壳使用亚克力项目盒或自制亚克力板，手工开孔装配。
- 不购买成品恒流 LED 驱动板；所有关键模拟器件按原理图自行连接和调试。

## 11. 关键公式与接线要点

### 11.1 公式

- 恒流关系：`I_LED = Vref / R_sense`，R_sense = 1Ω。
- 参考电压：`Vref = 3.3V × duty`，duty = 0.606%~6.06% 对应 20~200mA。
- 功率管功耗：`P = (Vrail - Vf - I_LED × R_sense) × I_LED`。
- 正常 200mA：`(4.7 - 3.2 - 0.2) × 0.2 ≈ 0.26W`。
- 短路 200mA：`(4.7 - 0.2) × 0.2 ≈ 0.9W`。
- 测量增益：`G = 1 + 9.1k / 1k = 10.1`。
- 显示电流：`I_display = ADC_voltage / (G × R_sense)`。
- 调光亮度：`brightness = 1 - CCR2 / ARR2`。

### 11.2 接线要点

- LED 阳极接 4.7V，阴极接 IRLZ44N 漏极 D；IRLZ44N 源极 S 接 1Ω 上端；1Ω 下端接星形地。
- IRLZ44N TO-220 正视（引脚朝下、散热片朝上）：从左到右 G、D、S。
- LM358 DIP-8：1=OUT A，2=IN A-，3=IN A+，4=GND，5=IN B+，6=IN B-，7=OUT B，8=VCC。
- BSS138 SOT-23：1=G，2=S，3=D。
- 1N5819：带色环一端为阴极，接负载侧。
- 数码管引脚因厂家不同而不同，焊接前先用万用表二极管档确认共阴端和各段引脚，再对照本文件的段选表接线。
- 1Ω 采样电阻的上端到 LM358 2 脚、下端到 LM358 4 脚各走独立线，不要共用大电流地线。
- 功率线（4.7V、LED、MOS、1Ω、地）用粗线并尽量短；栅极线短且远离功率线。
- 上电顺序：先接好 LED 和地，再上 5V；调试时用限流电源，限流设为 300mA，确认无误后再换 5V/2A 适配器。
- 首次上电不要直接接 LED，先断开 LED、用 10Ω/5W 假负载测试恒流环，确认电流受控后再接 LED。
